# 🌟 JavaScript Basics & Advanced Mastery

Welcome to **JavaScript Basics**! This repository is a comprehensive, modular, and completely runnable JavaScript reference handbook and project collection.

## 🚀 Highlights

- **11 Curated Modules**: From Core Syntax to Modern Async, OOP, ES6 Modules, and the DOM.
- **Zero Commented Out Code**: Every script is 100% active, clean, and executable without commenting/uncommenting hurdles.
- **Runnable Everywhere**:
  - Run **Core, OOP, and Async** scripts in your terminal using **Node.js** (`node <file>`).
  - Run **DOM, Events, and API** apps directly in your browser with interactive sandboxes!
- **Interactive Visual Dashboard**: Open [`js_basics/index.html`](file:///c:/Users/Abinanthan/Desktop/Javascript/js_basics/index.html) to search topics and launch demos directly.
